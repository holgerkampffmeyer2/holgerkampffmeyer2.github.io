# Proposal: Document Current Feature Set

## Overview
Document the existing baseline feature set, architecture, tech stack, and automation workflows of the holger-kampffmeyer.de website (Astro 6/7, Tailwind CSS 4, SSG).

## Purpose
Establish a clear OpenSpec baseline of all current features (Core Pages, DJ & Music Blog, Events & Portfolio, Build/SEO Automations) to serve as reference for future development.

## Scope
- Core pages (Home, Link-in-Bio, Impressum, Theme-system)
- DJ & Music Blog (Mixcloud integration, dynamic mix detail pages, weekly mixes archive, DJ Hulk landing page)
- Events, Portfolio & Vermietung (Work gallery, EM3F event, video showcase, event technology rental)
- Build & SEO Automations (Image optimization, RSS/URL list generation, IndexNow submission)
